# SOLMAR HEAT

A 2D top-down open-world crime adventure unfolds across Solmar Bay in the warm light of sunset. Play through seven story missions, including Sunset Run, tune in to three radio stations, and manage your respect meter while a golden-hour color grade sets the mood. Everything is delivered as static files with no network dependency.

## Run

```sh
node serve.ts
```

Then open http://localhost:8080 in a browser.
