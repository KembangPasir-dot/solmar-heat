A 2D top-down open-world crime game set in Solmar Bay at sunset, built for make.fun's "Make GTA 6" bounty ($1,666 in USDC).

Play as a driver in a coastal city: steal cars, outrun the police, build respect, and run seven story missions — including the timed Marina delivery "Sunset Run". Three synth radio stations (R cycles, M mutes), a wanted level, traffic and pedestrians, combat, and a golden-hour grade. Static files, no network needed.

## Run it

Serve it locally, then open http://localhost:8080:

```sh
node serve.ts
```

Or build the hand-in with the entrypoint (writes game/, screenshots/ and dossier.json to /output):

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
